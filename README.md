## 🚀 Quick Start

### Prerequisites

- Modern runtime environment (Python)
- Git

### Installation

```bash
git clone https://github.com/Tarunjit45/mujoco_warp.git
cd mujoco_warp
```

### Setup Virtual Environment

```bash
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### Run Tests

```bash
pytest
```
