## 🚀 Quickstart & Installation

### Prerequisites
- Python 3.9+
- pip package manager

### Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Tarunjit45/mujoco_warp.git
   cd mujoco_warp
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Execute application:**
   ```bash
   python main.py
   ```
